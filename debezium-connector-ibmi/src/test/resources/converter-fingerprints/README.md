# Pre-fix converter fingerprint fixtures

`legacy.json` contains two initialized binding-history records and their exact F/W
offsets generated by the pre-fix `As400DcgConfig` and `As400BindingHistory` classes
on 2026-11-08. The native definitions come from the existing sanitized
`native-transactions/open-clear-progress.json` fixture. These are local generated
history fixtures, not new IBM i captures. Every credential value is synthetic.

The first policy has no converter credentials. Its exact stored fingerprint must
continue to recover, including after adding or rotating recognized credentials.
The second policy hashes two credentials under the former behavior. It must reject
without rewriting history or offsets: the digest does not distinguish credential
changes from semantic changes. Do not regenerate this fixture using the fixed
policy, since that would erase the compatibility boundary the test covers.
